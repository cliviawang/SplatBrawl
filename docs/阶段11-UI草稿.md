## 6. GameHUD（游戏中信息面板）

> 现状：比分 / 倒计时挤在 `HUD.ts` 的顶部 28px 黑底条里，冲刺 CD 只在 `DebugHUD`（F1 调试浮层）能看到，玩家自己的技能槽只在角色头顶有一个小圆。本节把"对局进行中玩家需要看到的信息"重新规划成正式 HUD。

### 6.1 设计原则

1. **不挤占游戏区域**：HUD 占用顶部和底部各一条窄带，地图主体区域不缩。
2. **信息分层**：顶部放"全局对局信息"（倒计时、四方比分），底部放"玩家自身状态"（冲刺 CD、当前技能槽）。
3. **复用现有资源**：颜色全部走 AssetRegistry（`player.<color>` / `ui.bg` / `ui.text`），不新增颜色 key。
4. **几何图元优先**：圆环 / 矩形 / 文字组合，不等美术素材；后续若有图标再通过 AssetRegistry 的 `hasTexture` fallback 走图片分支。

### 6.5 底部 HUD 元素清单

#### 冲刺指示器（左下）

| 元素 | 位置 | 尺寸 | 行为 |
|------|------|------|------|
| CD 环背景 | `(40, h-36)` | 半径 22 灰圆 `0x444444` | 静态 |
| CD 环填充 | 同上 | 圆弧扇形 | `progress = 1 - cooldownRemaining / cooldownTotal`，0 → 满圆 |
| 冲刺图标 | 圆环中心 | 24px 文字"⚡"或"DASH" | Ready 时玩家色描边，CD 中灰色 |
| 文字标签 | `(80, h-36)` | 14px | "冲刺" / "冷却 1.2s" |

数据来源：从 `GameState.players[playerIndex].dashState` 读：
- `dashState.kind === 'idle'` → Ready 态
- `dashState.kind === 'dashing'` → 高亮（短暂闪烁）
- `dashState.kind === 'cooldown'` → 显示 CD 进度

#### 技能槽（右下）

技能在本游戏是"拾取即持有、使用即消耗为灰态、灰态可被冲刺抢走或被新技能覆盖、局末重置"的一次性模型。所以技能槽不是两态而是 **三态 + 一个眩晕叠加层**。

##### 三态可见状态

| 数据状态 | displayPhase | 视觉表现 | 语义 |
|----------|--------------|----------|------|
| `skillSlot === null` | `empty` | 半透明灰框 alpha 0.3，无图标，按键提示淡灰 | 空槽，去地图上捡 |
| `{ used: false }` | `active` | 玩家色边框 + 技能图标高亮 + 按键提示醒目 + 缓慢 pulse 动画（scale 1.0↔1.04，周期 1.5s） | 持有可用，按键即可释放 |
| `{ used: true }` | `spent` | 图标保留但置灰（tint `0x666666`）+ 边框变深灰 `0x555555` + alpha 0.5 + 无 pulse + 按键提示隐藏（或改为小字"已用"） | 已释放，仍挂在身上可被冲刺抢走，自己不能再用 |

> **关键：灰态不会自动消失。** 它持久保留在身上，直到被冲刺抢走 / 被新拾取覆盖 / 局末重置。所以 HUD 不做 fade-out 自动转空槽——空槽态只在数据真的变 `null` 时进入。

##### 眩晕禁用叠加层

眩晕中（`state.tick < player.stunUntilTick`）按技能键无效，需要额外可视化：

| 条件 | displayPhase | 叠加效果 |
|------|--------------|----------|
| `used: false` 且眩晕中 | `disabled` | 在 `active` 视觉之上叠红色半透明蒙版 + 🚫 / 斜线图标 |
| `used: true` 且眩晕中 | `spent` | 灰态本来就不可用，**不**叠加禁用蒙版 |

##### 状态切换动画

| 切换 | 动画 |
|------|------|
| `empty → active`（拾取） | pop-in 缩放 0.5→1.0（200ms ease-out）+ 边框闪一下白光 |
| `active → spent`（释放） | desaturate 200ms（边框 + 图标渐变到灰） |
| `active → disabled`（被眩晕） | 红色蒙版 100ms fade-in |
| `disabled → active`（眩晕解除） | 红色蒙版 100ms fade-out |
| `spent → active`（被覆盖：捡到新道具） | 灰态直接被新技能的 `empty → active` pop-in 覆盖 |
| `spent → empty`（被抢走） | 短 fade-out 150ms |
| `active → empty`（被抢走） | 短 fade-out 150ms |

##### 元素清单

| 元素 | 位置 | 尺寸 | 说明 |
|------|------|------|------|
| 技能图标背景 | `(w-80, h-36)` | 44×44 圆角矩形 | 边框颜色随状态变化（玩家色 / 深灰） |
| 技能图标 | 同上中心 | 28×28 | 持有时显示技能字母（火箭=R，炸弹=B…）；`spent` 时叠灰 tint |
| 按键提示 | `(w-110, h-36)` | 18px bold | 显示绑定键；`spent` / `empty` 态隐藏或灰化 |
| 禁用蒙版 | 覆盖整个背景 | 44×44 | 仅 `disabled` 态可见，红色 alpha 0.4 + 斜线 |

##### 数据来源

`GameState.players[playerIndex].skillSlot`：`null | { id: SkillId; used: boolean }`。

每帧从 GameState 同步，按以下规则推导 `displayPhase`：

1. `skillSlot === null` → `empty`
2. `skillSlot.used === false` 且未眩晕 → `active`
3. `skillSlot.used === false` 且眩晕中 → `disabled`
4. `skillSlot.used === true` → `spent`（不叠加 disabled）
